## P1 — Vídeo Demo (PRIORITARIO)

**Objetivo:** Mostrar en 30–45 segundos que WebHunter resuelve el problema de encontrar
y gestionar prospectos de negocios locales sin web.

### Script propuesto (storyboard)

```
[0–4s]  HOOK: Pantalla del mapa con negocios marcados
        Voz/texto: "¿Sabes cuántos negocios cerca de ti no tienen web?"

[4–12s] PROBLEMA: Muestra búsqueda manual en Google Maps, copiar datos a Excel
        Voz/texto: "La mayoría de freelancers pierden horas buscando clientes a mano"

[12–30s] SOLUCIÓN (DEMO): Screen recording de WebHunter
         - Buscar por ciudad/tipo de negocio
         - Ver lista de resultados con score IA
         - Click en prospecto → datos completos + pain points generados
         - Mover al pipeline
         Voz/texto: "WebHunter lo hace en segundos: busca, califica y contacta"

[30–40s] CTA: Logo + URL + oferta
         Texto: "Pruébalo gratis [URL] — El CRM para freelancers de web"
```

### Especificaciones técnicas

| Parámetro | Valor |
|-----------|-------|
| Formato | Vertical 9:16 (1080×1920) para Reels |
| Duración | 30–60s (< 15s pierdes contexto, > 60s baja retención) |
| Audio | Obligatorio (IG Reels penaliza sin audio) |
| Subtítulos | Sí — 85% ve Reels sin sonido |
| Texto en pantalla | Primera frase visible sin audio < 3s |
| Resolución mínima | 1080p |
| Herramienta | OBS Studio (gratis) para screen recording + CapCut/DaVinci para edición |

### Variantes A/B a probar (mes 2)

| Variante | Diferencia |
|----------|-----------|
| A | Hook con pregunta ("¿Cuántos negocios...?") |
| B | Hook con resultado ("Encontré 30 clientes en una tarde") |
| C | Hook con dolor ("Odio buscar clientes a mano") |

## P2 — Carrusel "Pain → Solución"

### Estructura de slides

| Slide | Contenido | Texto |
|-------|-----------|-------|
| 1 (portada) | Imagen impactante, texto grande | "El problema de encontrar clientes de web en 2026" |
| 2 | Ilustración de búsqueda manual | "Hora 1: Buscas en Google Maps" |

| 7 (CTA) | Logo + URL + CTA | "Empieza gratis → [URL]" |

### Especificaciones

| Parámetro | Valor |
|-----------|-------|
| Formato | 1080×1080 (cuadrado, funciona en Feed y Reels carrusel) |
| Slides | 6–8 (no más) |
| Fuente | Sans-serif legible en móvil, texto > 24px |
| Paleta | Usa los colores del branding de WebHunter |

## P3 — Static con oferta (Retargeting)

**Para quién:** Personas que visitaron la landing pero no convirtieron.

### Versiones

```
Versión 1 — Urgencia:
  Titular: "¿Todavía pensando en WebHunter?"
  Cuerpo: "Más de X freelancers ya lo usan. Pruébalo gratis."
  CTA: "Empezar ahora"

Versión 2 — Oferta:
  Titular: "50% de descuento el primer mes"
  Cuerpo: "Solo para freelancers que se registren esta semana."
  CTA: "Reclamar oferta"

Versión 3 — Social proof (cuando tengas reviews):
  Titular: "[Nombre] cerró 3 webs su primer mes"
  Cuerpo: Foto + cita breve
  CTA: "Ver cómo funciona"
```

### Especificaciones

| Parámetro | Valor |
|-----------|-------|
| Formato | 1080×1080 y 1080×1920 (hacer dos versiones) |
| Ratio texto/imagen | Texto < 30% del área de la imagen |
| Logo | Visible pero no dominante |
| CTA en la imagen | Breve: "Pruébalo gratis", "Empezar ahora" |
