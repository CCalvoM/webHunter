# WebHunter CRM — Roadmap de Implementación

---

## Fase 1 — Fundación (Semanas 1–2)
**Objetivo: tener el tracking listo y el primer creativo grabado antes de gastar 1€**

### Semana 1

| Tarea | Prioridad | Estimación |
|-------|-----------|-----------|
| Crear cuenta Meta Business Manager | P1 | 30 min |
| Crear Meta Pixel e instalarlo en la landing | P1 | 1h |
| Verificar dominio en Meta Business Manager | P1 | 15 min |
| Configurar eventos de conversión (Subscribe/Purchase) | P1 | 1–2h |
| Instalar Google Analytics 4 | P2 | 30 min |
| Grabar vídeo demo con OBS Studio (screen recording) | P1 | 2–4h |
| Editar vídeo demo con CapCut o DaVinci (subtítulos, música, CTA) | P1 | 1–2h |
| Revisar landing en móvil y medir velocidad (PageSpeed) | P1 | 30 min |

### Semana 2

| Tarea | Prioridad | Estimación |
|-------|-----------|-----------|
| Diseñar carrusel pain→solución en Canva | P2 | 2h |
| Crear 2 statics para retargeting (Canva) | P3 | 1h |
| Configurar audiencia personalizada "Visitantes web 30 días" en Meta | P1 | 15 min |
| Redactar copies de todos los anuncios (usa el Creative Brief) | P1 | 1h |
| Revisión final: Pixel Helper confirma todos los eventos | P1 | 30 min |

## Fase 2 — Lanzamiento (Semanas 3–4)
**Objetivo: primeras conversiones, validar el embudo, establecer baseline**

### Semana 3

| Tarea | Acción |
|-------|--------|
| Crear campaña de Prospecting en Meta | Sigue CAMPAIGN-ARCHITECTURE.md — Ad Sets A y B |
| Subir vídeo demo al Ad Set A | Formato 9:16, subtítulos quemados |
| Subir carrusel al Ad Set B | 6–8 slides, copy de anuncio versión media |
| Presupuesto inicial | 150 €/mes (conservador, aumenta en semana 5 si CPA es razonable) |
| Revisar todos los anuncios: ubicaciones, segmentación, URL destino + UTMs | — |
| Activar campaña | Lunes para aprovechar el ciclo de aprendizaje completo |

### Semana 4

| Tarea | Acción |
|-------|--------|
| Monitorear diariamente: gasto, impresiones, CTR | Alertas en Meta Ads Manager |
| Lanzar campaña de Retargeting | Solo si la landing ya tiene >100 visitantes únicos |
| NO tocar segmentación ni pujas | La fase de aprendizaje necesita al menos 7 días sin cambios |
| Registrar datos en tabla de seguimiento | Gasto, clics, CPA diario |

---

## Fase 3 — Optimización (Semanas 5–8)
**Objetivo: bajar CPA, escalar lo que funciona, matar lo que no**

### Semana 5–6

| Señal | Acción |
|-------|--------|
| CTR Ad Set A < 1% | Graba variante B del hook del vídeo |
| CTR Ad Set B < 0.8% | Rediseña slide 1 del carrusel (más impacto visual) |
| CPA < 50 € sostenido 7 días | Sube presupuesto +20% (de 150 € a 180 €) |
| CPA > 80 € sostenido 14 días | Pausa el ad set con peor rendimiento, analiza landing |
| Ad Set A gasta > 70% del budget | Meta te está diciendo que funciona mejor — déjalo |

### Semana 7–8

| Tarea | Acción |
|-------|--------|
| A/B test del hook del vídeo | Lanza variante B (mismo ad set, nueva creatividad) |
| Revisión de frecuencia | Si frecuencia > 3.5, añade nuevas creatividades o amplía audiencia |
| Activar Ad Set C (Broad) | Solo si tienes 30+ conversiones acumuladas |
| Añadir Google Ads Brand (si presupuesto lo permite) | 30–50 €/mes, keywords: "webhunter crm", "webhunter freelance" |

---

## Fase 4 — Escala (Meses 3–6)
**Objetivo: CPA < 40 €, 10+ suscriptores nuevos/mes, primer MRR estable**

| Mes | Acción |
|-----|--------|
| Mes 3 | Añadir Google Search Brand (30 €/mes). Revisar mix presupuestal. |
| Mes 4 | Si tienes 50+ suscriptores, crear Lookalike 1% sobre compradores. |
| Mes 5 | Evaluar TikTok Ads si Reels de Meta están saturados (audiencia joven). |
| Mes 6 | QBR: revisar LTV real vs estimado. ¿Vale la pena escalar más agresivo? |

---

## Cadencia de optimización semanal

| Frecuencia | Acción |
|-----------|--------|
| Diario | Revisa gasto vs presupuesto, alertas de CPA extremo |
| 2× semana | Revisa CTR y frecuencia de cada anuncio |
| Semanal | Revisa conversiones, decide si cambiar copy o creatividad |
| Mensual | Análisis completo: CPA, LTV, MRR generado vs inversión |

---

## Regla de 3 meses

Si a los 3 meses el CPA promedio está por encima de 60 € y no baja:
1. Revisa la landing page (puede ser el cuello de botella, no los ads)
2. Revisa el precio/oferta (un free trial reduce friction enormemente)
3. Prueba cambiar el ángulo creativo completamente (de demo a testimonial)
4. Si nada funciona, el canal de pago puede no ser el adecuado en esta etapa —
   considera SEO, contenido orgánico, o comunidades de freelancers primero.
